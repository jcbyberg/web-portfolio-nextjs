# Whitespace Content Ledger

This ledger tracks all brainstormed, drafted, and published content across the Whitespace Designs ecosystem to prevent duplicate ideas. 
**Agents must read this file before generating new ideas, and append new ideas to this file once they are drafted.**

**Drafts live in `drafts/<collection>/` at the repo root** — `joshbyberg`, `whitespace`, `ai`,
`race-dad`. The folder name is the collection name, which is also the first argument to
`content:post`, so a draft's path tells you how to ship it. That directory sits outside
`src/content/`, so the site loader and the content checker never see it (verified: `posts.js`
roots at `src/content`, and a check run reported 64 files across the four collections with the
29 drafts ignored).

Generating drafts is the `generate-whitespace-posts` skill; the file format is `blog-drafting`;
publishing is `write-blog-post`. Numbers in a draft must be verifiable on one of Josh's own
pages, cited to a named source, or left as arithmetic the reader does — never invented.
